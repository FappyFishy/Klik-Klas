# 🏨 Room Booking App (Java)

A web-based room booking system built with Java. Users can reserve, manage, and cancel room reservations. 
Includes role-based access for students and teachers.

## 🚀 Features

- 📅 Book rooms by time slot
- 👤 User roles: Student, Teacher and Admin
- 🔐 Login system with JWT security
- 📊 Teacher dashboard to view all bookings
- ❌ Cancel or edit reservations

---

## 🛠️ Tech Stack

- **Backend:** Java 
- **Database:** MySQL 
- **Frontend:**  HTML-CSS
- **Build Tool:** Maven 
- **Version Control:** Git + GitHub
